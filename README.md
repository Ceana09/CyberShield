🛡️ CyberShield

Think. Verify. Stay Safe.

CyberShield is a cybercrime and scam awareness website that helps users recognize online scams, understand warning signs, and learn how to stay safe online.

✨ Features
🚨 Awareness about common cyber scams
🔍 Educational Scam Detector
🎮 Spot-the-Scam Quiz
🔐 Cyber Safety Tips & Checklist
🆘 Steps to take after being scammed
📚 Cybersecurity Resources
📱 Responsive and user-friendly design
🎯 Objective

To educate, protect, and empower users against cybercrime through simple, interactive, and accessible cybersecurity awareness.

Learn → Recognize → Protect → Respond → Report
